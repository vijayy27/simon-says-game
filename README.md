# Simon Says Game

A memory-based game built using HTML, CSS, and JavaScript.

## Features
- Interactive gameplay
- Random color sequence generation
- Level progression
- Score tracking
- Responsive design

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Play
1. Press any key to start.
2. Watch the color sequence.
3. Repeat the sequence by clicking the buttons.
4. Complete each level to advance.
5. The game ends when you select the wrong sequence.
